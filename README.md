# Espectroscopía UV-Vis · Aplicaciones farmacéuticas

Presentación web estática (HTML + CSS + JavaScript vainilla) para el seminario de **Análisis Instrumental Farmacéutico**.

Diapositivas:

1. Carga y liberación de fármacos
2. Propiedades antioxidantes (DPPH, IC50)
3. Actividad y cinética enzimática (NADH, 340 nm)
4. Detección y biosensores (SPR de nanopartículas)
5. Reducción catalítica y síntesis (4-nitrofenol → 4-aminofenol → paracetamol)

Todas las gráficas se generan en SVG con JavaScript, sin librerías.

## Uso

Abrir `index.html` en el navegador (o publicarlo con GitHub Pages).

- `←` / `→`, espacio o deslizar: cambiar diapositiva
- `N`: notas del expositor (texto completo de cada aplicación)
- `F`: pantalla completa
